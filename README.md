# 小辉造镜师｜《我不是大师》风格蒸馏 Skill

版本：`v1.0.0`。把剧集参考中的镜头组织、人物关系、台词与画面质感转成原创创作规则，用于剧本、角色设计和六格分镜。

## 能做什么

- 写有欲望、秘密、选择和行动后果的原创场景剧本。
- 设计独立角色，固定身份与外形，再用定稿角色继续做镜头。
- 设计三列两行六格分镜，让动作、机位、视线与主动权变化推进剧情。
- 处理近身试探、互相压制和压抑感情；根据情境区分照料、强制、试探与亲密回应。
- 统筹光色、衣料、场景层次、道具状态及跨镜连续性。

完整方案输出十项，前五项是主要结果：

| 项目 | 交付内容 |
|---|---|
| 镜头 | 分镜、动作、景别、机位、构图与镜头图 |
| 台词 | 分角色对白及关键潜台词 |
| 剧情 | 梗概、完整场景、因果与伏笔 |
| 画面效果 | 光色、材质、空间与效果方案 |
| 人物角色 | 角色卡、关系、造型与独立角色图 |
| 表演调度 | 站位、距离、视线与动作目标 |
| 剪辑节奏 | 镜序、切点理由与原创时长建议 |
| 声音设计 | 原创环境声、音效、对白与音乐方案 |
| 场服道 | 场景、衣物、道具功能与连续性 |
| 方法应用 | 迁移依据、改造点与逻辑检查 |

## 豆包使用

读取 [完整创作规则](doubao/小辉造镜师_完整创作规则.txt)，上传给豆包或复制全文，附上：“按文件内的规则执行”。再提供创作任务与最终角色图。

[豆包单入口包](doubao/小辉造镜师_豆包单入口包-v1.0.0.zip)内只有一个完整规则文件；[使用说明](doubao/使用说明_放包外.txt)放在压缩包外。能否直接读取ZIP取决于豆包当前入口；读取不了时上传TXT。新对话重新提供规则与定稿图。

详细步骤见 [豆包使用说明](docs/豆包使用说明.md)。支持Skill目录的平台可使用 [标准Skill包](packages/xiaohui-shotmaker-skill-v1.0.0.zip)。

## 示例任务

> 按小辉造镜师规则，写一场两分钟、两人、一处账房的原创悬疑戏。十项全部输出。先分别定男女主，再用最终角色图画一张六格分镜。双方近距离试探，争夺证据与选择权，每格动作和机位不同。

## 素材与交付

本仓库包含创作规则、方法与原创示例，不包含原剧视频、截图或个人角色定稿图。使用者另行提供自己的参考素材与最终角色图。实际出图依赖所用平台的图像功能；文字分镜不能算作已交付的图片。
