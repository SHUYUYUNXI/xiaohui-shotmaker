# 小辉造镜师 v1.0.0｜豆包使用说明

用于角色设计、剧本创作、六格分镜与剧版画面效果。完整创作输出十项，重点是镜头、台词、剧情、画面效果和人物角色。

## 1. 提供创作规则

解压后打开 `豆包创作规则.txt`，复制全文到豆包新对话，发送：

> 以下是“小辉造镜师”的创作规则。请阅读，并在本次对话后续创作中按规则执行。先简短确认你理解了角色定稿、六格镜头和全新重画的区别，暂时不要生成作品。

规则较长时可以分段发送，并说明“尚未发送完，等全部规则发完再执行”。若当前入口支持读取文本文件，也可直接上传规则文件，以实际可读取的内容为准。

换新对话时重新提供规则与角色定稿图。不要只发技能名称，指望新对话自动取得之前的文件。

## 2. 先分别做角色

> 按“小辉造镜师”规则，先分别画男主、女主，每人一张独立角色图。民国悬疑剧质感。男主年轻成年、警觉、浅色合体西装；女主年轻成年、纤瘦高挑、长发、细花旗袍。角色图看镜头。先定角色，暂时不画镜头。

有风格参考时同时上传，说明“用于参考选角气质、造型和剧版质感”。补全身图时发送：

> 保留这张角色的脸、发型和服装，另设计全身动作与头部朝向，不照搬半身姿势。身体比例自然，不拉长腿、不缩小头。

满意后保存两张角色图，明确标注“男主定稿”“女主定稿”。后续以最终定稿为准。

## 3. 用定稿角色画六格镜头

在支持参考图创作的图片入口，上传最终男女主两张图，发送：

> 图1是最终男主，图2是最终女主。按“小辉造镜师”规则，用这两个人生成一张六格分镜，三列两行，每格横向画幅。每格保持同一张脸、发型、衣服与体型。男女主面对面极限贴近，有感情但互相试探、压制，不愿受对方控制。表情克制，有戒备与短暂动摇，不画甜笑摆拍。六格有不同动作、机位和主动权变化。先明确双方争夺什么，再实际生成镜头图。

如果图片入口不能读取此前长规则，将角色图、六个具体镜头描述及本次有关的风格要求一并提供。角色定稿图需作为本次图片创作的参考，不能只写角色姓名。

## 4. 再画一组全新的

仅上传最终角色图，发送：

> 用定稿男女主，从零画一组全新的六格镜头。重新设计动作过程、站位、机位与主动权变化，不编辑旧分镜、不沿用旧组构图、不只是换背景。保持人物身份和剧版质感。

要修改原图则说“修改这张图”，上传待修改图，列出要改的部分。全新重画与局部修改分开提出。

## 5. 完整十项创作

> 按“小辉造镜师”规则，写一场两分钟、两人、一处账房的原创悬疑拉扯戏。镜头、台词、剧情、画面效果、人物角色、表演调度、剪辑节奏、声音设计、场景服装道具、方法应用，十项全部输出。重点给完整剧本、分角色台词、独立角色图与一张六格分镜。已有定稿角色就沿用，不另换脸。

## 6. 出图检查

- 人物脸、发型、体型是否与最终角色图一致。
- 全身比例、手指、持物与肢体接触是否自然。
- 六格是否数量正确、动作不同、能连成事件。
- 双方是否面对面，眼神是否看对方，表情是否符合关系。
- 服装、配饰、光线与空间是否连续。

脸不一致时重新提供最终角色图，明确“这张是唯一人物依据”，不混入旧脸参考。具体出图功能以当前豆包入口为准。

## 包内文件

- `豆包创作规则.txt`：合并版规则，可复制或提供给豆包。
- `xiaohui-shotmaker/SKILL.md`：核心创作方法。
- `xiaohui-shotmaker/references/`：十项方法、剧版风格、角色与镜头流程、原创示例与素材蒸馏规则。

包内不含原剧视频、截图或人物定稿图。使用时提供自己的角色与风格参考。使用方式是向豆包提供文字规则与参考图，无需安装技能文件夹。

豆包入口：[豆包官网](https://www.doubao.com/)。文件与参考图功能说明：[云盘使用须知](https://www.doubao.com/legal/ai_space)、[图片创作相关说明](https://www.doubao.com/legal/ai_replica)。
